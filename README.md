# Veterans Resource Hub · Connected v2

A GitHub-ready expansion of the existing **Veterans Resource Hub · One Door · No Wrong Door**.

Upload `index.html` over the existing page. The `docs/` files are optional project documentation.

Major additions:
- opt-in local Veteran resource navigator;
- Career Star + My Next Move for Veterans;
- VA VR&E + American Job Centers;
- Khaemenes Higher Learning + GI Bill comparison + Khaemenes financial-aid tool;
- SBA VBOC, Boots to Business and VetCert;
- prominent One Nation For All civic bridge;
- broader homelessness/stability bridge to One Door;
- expanded public/veteran directory.
